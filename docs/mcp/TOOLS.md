## Tier `read`

### app_status

**Application status** · read-only, idempotent

Returns xournalai's version, MCP connection info, granted permissions, a summary of the open document (path, modified flag, page count, current page) and the user's active tool. Call this first to orient yourself.

### blocks_render

**Render content blocks** · read-only, idempotent

Renders tight, high-resolution crops of layout blocks (from layout_analyze) or of the area covering given elements, one image per block, each captioned with its block id, kind and bbox. Use split_lines=true to get one image per handwritten text line for accurate transcription.

| `block_ids` | array of string |  |  | Blocks from layout_analyze, e.g. ["b1", "b3"] |
| `dpi` | number |  | `200` | Resolution; 72 = 1 pixel per point |
| `element_ids` | array of string |  |  | Render the area covering these elements instead |
| `grid` | boolean |  | `false` | Overlay a labelled grid in page points (helps to place drawings precisely) |
| `grid_step` | number |  | `50` | Grid spacing in points |
| `max_images` | integer |  | `12` | Maximum number of images returned |
| `max_px` | integer |  | `1400` | Maximum size of the longer image side |
| `padding` | number |  | `6` | Margin around each crop in points |
| `page` | integer |  |  | Page number (1-based); default: current page |
| `save` | boolean |  | `true` | Also save the PNG to a file and return its path (for clients that cannot show images) |
| `split_lines` | boolean |  | `false` | Render each text line of handwriting blocks as its own image (best for reading handwriting) |

### layout_analyze

**Analyze page layout** · read-only, idempotent

Groups the content of a page into blocks in reading order: handwriting (with text line boxes), figure (drawings, diagrams, schematics), highlight, typed_text, latex, image, link; plus connectors (long straight strokes such as arrows linking blocks, with the blocks at each end). Blocks inside a figure (labels) name it as parent. Typed text and LaTeX sources are included verbatim. This is a heuristic map to decide what to look at: then call blocks_render to see the blocks and read the handwriting.

| `layer` | integer |  |  | Only this layer (1-based) |
| `page` | integer |  |  | Page number (1-based); default: current page |
| `region` | array of number |  |  | Only this area [x, y, width, height] in page points |

### notes

**Notes memory**

Remembers what you worked out about the document so you (or another agent) need not re-read it: transcripts of handwriting, summaries, the meaning of figures. op=set stores text for the document, a page, or a region of a page (one note per place and kind; set again to replace, empty text deletes); op=get returns the notes, filtered by page, kind and region (overlapping). Notes are saved next to the document file (<file>.ai-notes.json) and follow its pages when they are moved.

### page_elements

**Page elements** · read-only, idempotent

Lists the content of a page, bottom to top: strokes (handwriting and drawings), typed text, LaTeX, images and links. Each element has a stable id (e.g. "e42") usable by other tools, its layer, bbox [x,y,w,h] and color. detail=bbox is a cheap overview (text content included); simplified adds style and stroke points simplified to 'tolerance' points; full returns every point. Stroke points are [x,y] or [x,y,w] where w is the pressure-dependent width. Use region to focus on an area and offset/limit to page through busy pages. To *see* handwriting, use page_render instead.

| Argument | Type | Required | Default | Description |
|---|---|---|---|---|
| `detail` | `bbox` \| `simplified` \| `full` |  | `"simplified"` | Level of detail |
| `layer` | integer |  |  | Only this layer (1-based) |
| `limit` | integer |  | `200` | Maximum number of elements to return |
| `offset` | integer |  | `0` | Skip this many matching elements |
| `page` | integer |  |  | Page number (1-based); default: current page |
| `region` | array of number |  |  | Only elements intersecting this area as [x, y, width, height] in page points |
| `tolerance` | number |  | `0.5` | Simplification tolerance in points (detail=simplified) |
| `types` | array of `stroke` \| `text` \| `latex` \| `image` \| `link` |  |  | Only these element types |

### shapes_recognize

### thinking

### user_style

**The user's pen style** · read-only

### wait_for_user

**Wait for the user** · read-only

Waits until the user has changed something (drawn, erased, moved, typed ...) and then paused for idle_ms, and returns what changed, the affected area, an image of it and the user's current tool and page - so you can react to what they are drawing. Loop: wait_for_user → respond (in chat or by drawing) → wait_for_user(since=<cursor>). Returns timed_out=true if nothing happened. Keep timeout_s below your client's tool-call timeout.

| Argument | Type | Required | Default | Description |
|---|---|---|---|---|
| `idle_ms` | integer |  | `1500` | Pause after the last change before returning |
| `page` | integer |  |  | Only changes on this page (1-based) |
| `region` | array of number |  |  | Only changes intersecting [x, y, width, height] |
| `render` | boolean |  | `true` | Include an image of the changed area |
| `since` | integer |  |  | Only changes after this cursor (default: from now) |
| `timeout_s` | integer |  | `120` | Give up after this many seconds |

## Tier `draw`

### create_from_svg

**Draw an SVG**

Converts an SVG drawing into editable strokes (paths, rect, circle, ellipse, line, polyline, polygon, groups and transforms; stroke/fill colors, opacity, dashes) and <text> into text boxes, placed on the page (1 SVG unit = 1 point, or fitted into 'target'). Best way to draw complex illustrations. Optional pressure 'profile' and 'tremor' make it look hand-drawn. Gradients use their first color. One undo step, the default layer (the user's current layer unless they chose e.g. "AI"; see app_status); returns ids and warnings.

| Argument | Type | Required | Default | Description |
|---|---|---|---|---|
| `animate` | boolean |  |  | Draw progressively so the user sees it being drawn (default from settings) |
| `color` | string |  |  | Draw everything in this color instead of the SVG colors |
| `fit` | `contain` \| `cover` \| `none` |  | `"contain"` | How to fit into target |
| `layer` | string |  |  | Target layer: "current" (the user's selected layer), "AI" (a separate layer created on top, which the user can accept, hide or clear), a layer name or "#<n>". Default: the user's setting (app_status default_layer) |
| `new_page` | boolean |  |  | Append a new page and draw there (ignores 'page') |
| `page` | integer |  |  | Page (1-based); default: current page |
| `path` | string |  |  | Or: an .svg file to read |
| `profile` | `none` \| `constant` \| `ink` \| `brush` \| `pencil` \| `calligraphy` \| `marker` \| `match_user` |  |  | Optional pressure profile for a hand-drawn look (default none) |
| `scale` | number |  |  | Without target: SVG units per page point (default 1) |
| `speed` | number |  |  | Animation speed factor (1 = about hand speed) |
| `svg` | string |  |  | SVG document text (<svg ...>...</svg>) |
| `target` | array of number |  |  | Fit the drawing into this page area [x, y, width, height] |
| `tremor` | number |  |  | Hand tremor amplitude in points (default 0) |
| `x` | number |  |  | Without target: page x of the SVG origin (default 0) |
| `y` | number |  |  | Without target: page y of the SVG origin (default 0) |

### transaction_begin

**Begin an edit transaction**

Starts preparing one change of the canvas while others work in parallel (up to 5 at once). Claims an area of a page (no two transactions may overlap) and returns a private draft layer: draw the new content there with the normal tools (layer=<draft_layer>). Nothing is visible until transaction_commit, which plays everything in order as ONE undo step. Transactions not committed within 10 minutes are aborted.

| Argument | Type | Required | Default | Description |
|---|---|---|---|---|
| `base_ids` | array of string |  |  | Element ids your change depends on |

| `page` | integer |  |  | Page (1-based); default: current page |
| `region` | array of number |  |  | The area you'll work in [x, y, width, height] (default: the whole page) |
| `zone` | integer |  |  | The thinking zone of this request (from the wake-up line), if any |

### transaction_commit

**Commit an edit transaction**

Applies a transaction as ONE undo step: its operations are played in order, each commit after the previous one (never interleaved with other agents' edits). ops is an ordered list of: {"op":"draw", "animate":true|false, "speed":1} (the draft's content: stylus-like when animate, else instant), {"op":"delete","ids":[…]}, {"op":"restyle","ids":[…],"color":"#rrggbb","width":1.4,"fill":-1..255}, {"op":"move","ids":[…],"dx":0,"dy":0}. Example for improving strokes: [{"op":"draw","animate":true},{"op":"delete","ids":[the user's old strokes]}]. If the draft has content and no draw op is given, it is drawn at the end. When strokes you depend on changed since transaction_begin, the commit is refused with a reason (conflict): re-read, adjust, commit again, or transaction_abort. The drawing goes to the layer set in the user's settings.

| Argument | Type | Required | Default | Description |
|---|---|---|---|---|
| `ops` | array of object |  |  | Ordered operations (see the description) |
| `transaction` | string | yes |  | Transaction id (from transaction_begin) |

### ui_file_chooser

**Fill a file dialog**

Operates an open file dialog (Open, Save, Export, image or PDF chooser - see ui_windows): sets the path and confirms it (or cancels). For Save dialogs the file name is set in the name field.

| Argument | Type | Required | Default | Description |
|---|---|---|---|---|
| `accept` | boolean |  | `true` | Confirm (true) or cancel (false) |
| `path` | string |  |  | File to choose / save to |
| `window` | string |  |  | File dialog id (default: the open file dialog) |

## Prompts

| Prompt | Description | Arguments |
|---|---|---|
| `summarize` | Summarize what is written and drawn on a page | `page` |
| `extract_text` | Transcribe all handwriting and text of a page | `page` |
| `explain_figure` | Explain a drawing, diagram or schematic | `page`, `focus` |
| `draw` | Plan and draw a picture or diagram from a text description | `description`, `page` |

## Resources

| URI | Type | Description |
|---|---|---|
| `xournal://document` | application/json | The open document: path, pages, layers, current page (JSON) |
| `xournal://changes` | application/json | The latest document changes (user and agent), newest last (JSON) |
| `xournal://page/{page}` | application/json | Elements of a page (ids, types, bboxes, text) as JSON |
| `xournal://page/{page}/image` | image/png | A PNG rendering of a page |

Resources support `resources/subscribe`; updates arrive as `notifications/resources/updated` on the SSE stream (and through `xournalpp --mcp-stdio`).
